六、AI 流式解读 （M4 · 盘面+格局+用神 → 提示词 → OpenAI 兼容接口，流式输出）

服务端代理（线上默认）：请求发本站 /api/interpret，密钥可在服务端配置为 secret，浏览器无需填密钥；每次解读写入 D1 留痕（IP 仅存哈希）。 中转站等自定义供应商由后台 CUSTOM_PROVIDERS 配置，配好后自动出现在上方模型芯片中。 前端直连（本地双击打开默认）：密钥仅存本机 localStorage，请求直发所填接口、不经中间服务器；要求接口支持 OpenAI 兼容 /chat/completions 与 stream:true， 若报 CORS 跨域说明该接口不允许浏览器直调。 多轮追问沿用同一盘面（模型侧受「追问沿用原盘」契约约束）；盘面事实不可改写、主次次序、现实边界三条契约随提示词下发。
